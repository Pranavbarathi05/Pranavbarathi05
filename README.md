## 🏗️ Distributed Recruitment Platform

A multi-machine recruitment platform designed around separated application, compilation, and gateway infrastructure.

### Architecture

```text
                    ┌──────────────┐
                    │   Gateway    │
                    └──────┬───────┘
                           │
             ┌─────────────┴─────────────┐
             │                           │
      ┌──────▼──────┐             ┌──────▼──────┐
      │    App-1    │             │    App-2    │
      │ Application │             │   Replica   │
      └──────┬──────┘             └─────────────┘
             │
      ┌──────▼──────┐
      │  Compiler-1 │
      │ Code Runner │
      └─────────────┘
```

### Engineering Focus

* Distributed service deployment
* Gateway architecture
* Application-server separation
* Dedicated compilation infrastructure
* Inter-machine communication
* Service isolation
* End-to-end deployment testing
* Horizontal replication

The architecture is designed to scale beyond the initial deployment by adding application and compiler replicas.
